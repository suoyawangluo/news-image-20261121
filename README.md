## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to `/output/entry.png`. The run is deterministic: both runs write the same bytes. The page was designed in `design.html` and rendered locally to `entry.png` (1024×1024 PNG).
